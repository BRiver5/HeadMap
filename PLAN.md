# HeadMap — План реализации

> «See the pattern behind the pain.»
> Локальный дневник головной боли: приступы на 24-часовых циферблатах месяца,
> зоны боли на схеме головы и анализ связи «фактор дня → болевой день» с
> порогами надёжности.

---

## 0. Архитектурные решения

### 0.1 Полностью локальное приложение

Бэкенда нет. Источник правды — `expo-sqlite` на устройстве. Ни регистрации, ни
интернета, ни аналитики. Единственные системные возможности — локальное
уведомление (ежедневный чек-ин) и вибрация.

### 0.2 Разрешения

| Разрешение | Зачем |
|---|---|
| `POST_NOTIFICATIONS` | ежедневное напоминание отметить день (выключено по умолчанию, включается тумблером в Settings) |
| `VIBRATE` | тактильный отклик на выбор силы боли, зон и сохранение записи |

Ничего из `blockedPermissions` не разблокировано: камера, микрофон, геолокация,
точные будильники и медиа-доступ приложению не нужны.

### 0.3 Медицинская рамка

Приложение — **журнал и описательная статистика по собственным данным
пользователя**, не диагност и не советчик. Формулировки на экранах нейтральные
(«в твоём журнале болевых дней после этой отметки больше»), рекомендаций по
приёму препаратов нет, лимит дней с приёмом задаёт сам пользователь. Дисклеймер
стоит на Insights и в Settings.

## 2. Дизайн-система

```
background   #F2F1F5   (холодный пепельный, НЕ белый — экран открывают при светочувствительности)
surface      #FFFFFF
accent       #7E2F6E   (орхидея/шелковица, hue ~307°)
ink          #241F2C
```

Тёмная палитра — отдельно подобранная (фон `#17141C`, акцент `#C578B4`),
переключатель Light/Dark/System в Settings, по умолчанию **light**. Все
компоненты в `src/components/*` ходят через `useAppTheme()`, голый `useTheme()`
в приложении не используется.

Шкалы графиков (`src/theme/dataviz.ts`) прогнаны через валидатор dataviz-скилла:
ординальная шкала силы боли (один оттенок, светлый и тёмный варианты),
ординальная шкала частоты по зонам головы в семье акцента, категориальный набор
для легенд. Анимации — на `withTiming`/`withDelay` (spring только в press-фидбеке
`PressableScale`), тайминги из `src/theme/motion.ts`.

Layout-архетип — **Calendar-first**: месяц и есть главный экран, FAB нет,
добавление начинается тапом по дню. Навигация — три иконки в компактном хедере,
без нижнего таб-бара.

## 3. Модель данных

| Таблица | Поля |
|---|---|
| `attacks` | id, day, started_at, ended_at (NULL = идёт), severity 1..10, note, created_at |
| `attack_regions` | attack_id, region (8 зон головы) |
| `doses` | id, attack_id, med_key, taken_at, day |
| `day_logs` | day, logged_at — «день отмечен», знаменатель всей статистики |
| `day_factors` | day, factor_key (19 пресетов в 4 группах) |
| `settings` | key, value |

`day_logs` — ключевая сущность: без дней **без** приступа сравнивать не с чем,
поэтому пустой день, сохранённый как «ничего не было», — полноценная запись.

## 4. Экраны

1. **Calendar** (`app/index.tsx`) — месяц из 24-часовых циферблатов: дуга = от
   начала до конца приступа, цвет = сила боли; точка = день отмечен без боли.
   Внизу — две плитки с накручивающимися числами (дней без боли, приступов за
   месяц) и легенда шкалы.
2. **Day sheet → Attack sheet / Factors sheet** (модалки) — тап по дню открывает
   шторку дня, из неё два явных действия: «Log attack» (время, сила по шкале
   1..10, зоны на схеме головы, препараты с временем приёма, заметка) и «Day
   factors» (чипы пресетов). Пустой день показывает чеклист «с чего начать».
3. **Insights** (`app/insights.tsx`) — готовность к анализу, связи факторов с
   болевыми днями (доли, интервалы, лаг 0/1), сцепленные факторы, время до
   облегчения после препарата, ритм по дням недели и часам.
4. **Stats** (`app/stats.tsx`) — 6 секций: плитки-рекорды, болевые дни по
   неделям (BarChart), сила боли (DonutChart), схема головы с частотой по зонам,
   круговая гистограмма начала + длительности, кольцо дней с приёмом за 30 дней.
5. **Settings** (`app/settings.tsx`) — тема, ежедневное напоминание, личный лимит
   дней с приёмом, удаление данных, дисклеймер.

## 5. Алгоритмическая часть (`src/lib`, покрыта тестами)

- `statsMath.ts` — интервал Уилсона, разница долей по Ньюкомбу, круговая
  статистика часов, коэффициент Жаккара.
- `triggers.ts` — связь «фактор → болевой день» на лаге 0 и 1, пороги
  надёжности, отсечка «не отделяется от случайности», поиск сцепленных пар
  факторов, которые данными не разделяются.
- `medication.ts` — время до облегчения с честным цензурированием (незакрытые
  приступы и приступы с несколькими препаратами не растворяются в медиане),
  сравнение раннего и позднего приёма, счётчик дней с приёмом.
- `rhythm.ts` — круговое среднее времени начала с порогом концентрации,
  выделение дня недели только если нижняя граница интервала выше общей доли.
- `episodes.ts` — приступы через полночь, серии чистых дней, недельные корзины,
  полосы силы, частоты по зонам.

23 юнит-теста (`node --test`).
