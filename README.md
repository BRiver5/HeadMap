# HeadMap

**See the pattern behind the pain.**

Локальный дневник головной боли. Приступ записывается за полминуты: время, сила
по шкале 1..10, зоны на схеме головы, препарат и время приёма. Месяц целиком
виден как сетка 24-часовых циферблатов — по ним сразу читается не только «в
какие дни болело», но и «в какое время суток и как долго». Отдельный экран
Insights считает связь дневных факторов (сон, еда, стресс, погода) с болевыми
днями — с порогами надёжности, сдвигом на сутки и честным «эти два фактора
твоими данными не разделяются».

## Особенности

- **Календарь-циферблаты** — каждый день месяца это 24-часовое кольцо, дуга идёт
  от начала приступа до конца, цвет дуги = сила боли. Приступ через полночь
  рисуется на обоих днях своим куском.
- **Схема головы** — 8 зон, тап в форме приступа, на Stats та же схема
  закрашена частотой по зонам.
- **Анализ факторов** — доли болевых дней с фактором и без, интервалы Уилсона,
  разница долей по Ньюкомбу, лаг 0 и 1 сутки, отсечка «не отделяется от
  случайности» и поиск сцепленных пар факторов.
- **Препараты** — время от приёма до конца приступа с цензурированием:
  незакрытые приступы и приступы с несколькими препаратами не растворяются в
  медиане, а показываются отдельным числом. Счётчик дней с приёмом за 30 дней
  против лимита, который пользователь задаёт сам.
- **Ритм** — круговое среднее времени начала (полночь и 23:00 — соседние часы) и
  выделение дня недели только с запасом по неопределённости.
- Тема Light/Dark/System, по умолчанию светлая; тёмная — для дней, когда свет
  сам по себе проблема.

Приложение описывает собственный журнал пользователя. Оно не ставит диагнозов и
не даёт рекомендаций по лечению.

## Стек

- Expo SDK 54 + expo-router, TypeScript
- `expo-sqlite` — вся persistence локально на устройстве, интернет не нужен
- `react-native-svg` + `react-native-reanimated` — циферблаты, схема головы,
  круговая гистограмма, анимации входа
- `expo-notifications` (ежедневный чек-ин), `expo-haptics`

## Запуск

```bash
npm install
npx expo start
```

`a` — Android, `i` — iOS, либо QR-код через Expo Go.

## Структура проекта

```
app/            expo-router экраны (calendar, insights, stats, settings)
src/
  theme/        палитра, типографика, отступы, анимации, шкалы графиков
  db/           expo-sqlite схема + миграции
  data/         доступ к данным (attacks, days, settings)
  services/     notifications, haptics
  components/   UI-примитивы + DayDial, HeadDiagram, OnsetClock, шторки
  lib/          даты, пресеты и вся статистика (с юнит-тестами)
tools/          генератор иконок, проверки, rename-скрипт
```

## Проверки

```bash
npm run verify   # tsc + node --test + check-rules + expo export
```

## Данные

Всё хранится локально на устройстве. Регистрации нет, интернет для работы не
нужен, данные никуда не отправляются.
